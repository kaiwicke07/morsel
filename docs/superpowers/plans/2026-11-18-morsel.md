# Morsel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An installable iPhone web app that matches Cal AI's features: AI photo/label/describe logging, barcode, search, exercise, water, progress, badges.

**Architecture:** Vite + React + TypeScript SPA, PWA via vite-plugin-pwa, data in IndexedDB (Dexie). Pure logic in `src/lib` with Vitest tests; screens in `src/screens`, shared UI in `src/ui`. AI calls go straight from the phone to Claude (SDK, browser mode) or Gemini (REST), behind one `ai` interface.

**Tech Stack:** React 18, TypeScript, Vite 5, vite-plugin-pwa, Dexie 4 + dexie-react-hooks, @anthropic-ai/sdk, @zxing/browser (barcode fallback), Vitest.

**Spec:** `docs/superpowers/specs/2026-11-18-morsel-design.md`

## Global Constraints
- Name "Morsel"; no Cal AI name, logo or copy anywhere.
- Colors: paper #F3EDE2, ink #1E1915, paprika #D4471C, protein plum, carbs saffron, fat olive; dark = espresso. Fonts Fraunces + Instrument Sans. Bar meters, no rings.
- Claude model `claude-opus-5-5`; key stored only in IndexedDB on device; never committed.
- Imperial default (lb, ft/in), metric toggle; store everything in kg/cm internally.
- Base path `/morsel/` for GitHub Pages.
- iPhone: safe-area insets, 16px inputs (no zoom), no 100vh, apple-touch-icon, standalone display.

## Review Focus
- AI returns malformed / partial JSON or refuses → entry shows "Couldn't read that" with Retry; photo kept. (test: `parseFoodResult` rejects bad shapes)
- No API key set and user taps Scan → prompt to add key, not a crash.
- Barcode not in Open Food Facts → "Not found" with manual add fallback. (test: `normalizeOff` returns null for status 0)
- Servings changed to 0.5 or 2.5 → all nutrients scale, ingredients too. (test: `scaleEntry`)
- Day with no logs yesterday → no rollover; streak counts today-or-yesterday ending. (tests in day/streak)

### Task 1: Scaffold + pure logic

**Files:** Create `package.json`, `vite.config.ts`, `tsconfig.json`, `index.html`, `src/lib/plan.ts`, `src/lib/exercise.ts`, `src/lib/day.ts`, `src/lib/streak.ts`, `src/lib/badges.ts`, `src/lib/units.ts`, `src/lib/types.ts`, tests in `src/lib/*.test.ts`.

**Interfaces (Produces):**
- `computePlan(p: Profile): Targets` — Targets `{kcal, protein, carbs, fat, fiber, sugar, sodium, water}`; Mifflin-St Jeor, activity 1.375/1.55/1.725, pace lb/wk × 500, floors 1200 F / 1500 M; fat 27%, protein 0.8 g/lb clamped to 25-35% kcal, carbs rest.
- `goalDate(p: Profile, from: Date): Date | null`
- `exerciseKcal(kind: 'run'|'lift', intensity: 1|2|3, minutes: number, kg: number): number` — MET run 3.5/9.8/14.5, lift 3.5/5/6.
- `dayTargets(base: Targets, opts: {burned: number, addBurned: boolean, rollover: number}): Targets`
- `rolloverFrom(yesterdayKcal: number, yesterdayTarget: number, hadFood: boolean): number` — min(200, max(0, target − eaten)) or 0.
- `sumEntries(entries: FoodEntry[]): Nutrients`, `scaleEntry(e: FoodEntry, servings: number): FoodEntry`
- `currentStreak(loggedDays: Set<string>, today: string): number`
- `earnedBadges(stats: BadgeStats): Badge[]`
